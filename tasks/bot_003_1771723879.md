Task: Investigate a performance bottleneck in the mobile app's data loading.
AI Response: A common challenge!

To investigate a performance bottleneck in the mobile app's data loading, I'd follow these steps:

1. **Identify the affected features**: Determine which features or screens are experiencing slow data loading.
2. **Collect metrics**: Use tools like React Native's `Performance` module or Google's Chrome DevTools to gather metrics on:
	* Load times (e.g., network requests, data parsing)
	* CPU usage
	* Memory allocation
3. **Analyze code**: Review the code for potential bottlenecks:
	* Network requests: Are we making too many requests? Are they optimized?
	* Data processing: Is there excessive computation or unnecessary parsing?
4. **Simplify and test**:
	* Simplify data loading to isolate issues (e.g., remove unnecessary data)
	* Test with different network conditions (e.g., fast/slow networks, Wi-Fi/Cellular)

Example code snippet:

```javascript
// Before optimization
fetch('https://example.com/data')
  .then(response => response.json())
  .then(data => {
    // Process large dataset
    const processedData = data.map(item => item.name);
    // Render the data
  });

// After optimization (e.g., using React Native's `Performance` module)
import { Performance } from 'react-native';
const performance = new Performance();

fetch('https://example.com/data')
  .then(response => response.json())
  .then(data => {
    performance.measure('Data Loading', () => {
      const processedData = data.map(item => item.name);
      // Render the data
    });
  });
```

In this example, we're optimizing data loading by using React Native's `Performance` module to measure the "Data Loading" operation and reducing processing overhead.
