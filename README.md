## 🧐 عن المشروع (About)

مشروع **oda** هو جسر تقني يربط بين الثقافات. يهدف المشروع إلى معالجة مشاكل الترجمة الآلية التقليدية في الأدب، من خلال توفير بيئة ذكية لترجمة الروايات والقصص من وإلى أي لغة بشكل يحافظ على السياق الأدبي والمعنى الفني.

---

## ✨ المميزات (Features)

- [x] **دعم لغوي شامل:** دعم واسع لجميع لغات العالم.
- [x] **واجهة عصرية:** تجربة مستخدم سلسة باستخدام React و Vite.
- [x] **نظام إدارة خلفي قوي:** مبني على Django لضمان الأمان والسرعة.
- [x] **ترجمة مدعومة بالذكاء الاصطناعي:** تحافظ على السياق الأدبي والأسلوب الأصلي.
- [x] **تطبيقات الجوال:** قادمة قريبًا لتجربة قراءة متكاملة على جميع الأجهزة.
